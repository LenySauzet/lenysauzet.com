question: How do you use AI in your own development work?
topics: [ai, workflow, tooling]
---

Every day, and deliberately. I work with Claude Code and Cursor, use Codex and CodeRabbit, and build my own MCP tools and agents when a workflow repeats. At Tolk.ai I brought AI-assisted development into the team.

On my own projects I treat the agent's setup as part of the codebase: rules for each part of the code, skills for each kind of task, evals that check the agent loads the right ones, and the same gate as CI (lint, types, tests, build) before anything counts as done. Ankhora, my first XR application in Unity, was built with AI in the development pipeline from the start.
